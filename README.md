Este repositório foi criado como um projeto da disciplina 
Metodologias de Ensino em Computação, da Universidade Federal Rural de pernambuco (UFRPE), Ministrada por Rozelma França.

Este é um projeto de Jogo lúdico e desplugado para o ensino da Habilidade **(EM13CO10)** "Conhecer os fundamentos da Inteligência Artificial, comparando-a
com a inteligência humana, analisando suas potencialidades, riscos e limites." BNCC Computação - Ensino Médio.

Queria não apenas criar o jogo mas também deixa-lo disponível para o uso de professores em sala de aula ou ambientes educativos. 

Os arquivos foram criados utilizando Inteligência artificial, porém passam por um processo de validação e há perspectivas de avanço no código posteriormente, há coisas que ainda precisam ser desenvolvidas (WIP). 

A ideia é utilizar informações reais para criar dinâmicas informativas para os alunos sobre o mercado de IA e as nuances atreladas a elas.
